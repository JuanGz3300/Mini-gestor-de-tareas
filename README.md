# Mini-gestor-de-tareas-Inteligente

APLICATIVO WEB DESARROLLADO COMO PRUEBA TECNICA

# TECNOLOGIAS UTILIZADAS
    -- PHP -- Este para la logica del backend CRUD y manejo de datos

    -- JSON -- Sistema de almacenamiento de informacion ligero sin bd de por medio
    
    -- HTML5/CSS/Bootstrap --  Estructura visual y un diseño responsive
    
    -- JavaScript Jquery AJAX -- Comunicaion asincornica con API externa

    -- SweetAlert2 -- Mostrar alertas interactivas y atractivas

    -- FontAwesome -- Iconos de la interfaz

    -- API EXTERNA -- Advice Slip API -- (https://api.adviceslip.com/advice) Obteniendo consejos aleatorios al completar tareas   

# FUNCIONALIDADES

    1. Agregar tarea permitiendo registrar los pendientes en el campo de texto

    2. Ver tarea mostrando la lista de tareas ordenadas cronologicamente con su estado actual de pendiente o completada

    3. Finalizar tareas al hacer click en el boton de exito consumimos la API mostrando un mensaje motivacional en una ventana emergente

    4. Eliminar tarea permitiendo borrar elementos de la lista

# INSTRUCCIONES PASO A PASO PARA EJECUTAR EL APLICATIVO WEB

    1. REQUISITOS:
     * Tener instalado un servidor local que soporte php como XAMPP si no cuenta con el puede descargarlo facilmente en la pagina web oficial e instalarlo

    2. Clonar o descargar el repositorio
     *Descargue el codigo fuente o clonelo en la carpeta de su servidor local dentro de htdocs 

    3. Ejecutar el servidor
     *Encender el servicio de apache en la aplicacion XAMPP
    
    4. Abrir el navegador
     *Abra el navegador web de su preferencia y entra a 
     `http://localhost/nombre-de-tu-carpeta-donde-clonaste-y-pusiste-el-codigo`

     Con esto ya puedes probar y usar completamente el aplicativo web para agregar completar y eliminar tareas
